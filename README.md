# R-skill

R 语言绘图与数据整理专家（原顶刊科研绘图）。覆盖四大模块：① 数据清洗与重塑（tidyverse 管道、宽长互转、缺失/异常值治理）；② 出版级可视化（Nature/Science/Cell 级 360+ 类图）；③ 统计增强与多图排版（显著性标注、patchwork、plotly、gganimate）；④ 规范化输出与 AI 协同（矢量导出、数值溯源、可重现）。当用户要绘制科研图表（柱状/箱线/小提琴/热图/火山图/曼哈顿图/桑基/韦恩/环状/旭日/雷达/森林图/生存/ROC/PCOA/PCA/NMDS/Mantel 网络/GO-KEGG 富集/进化树/基因组圈图/单细胞 UMAP 等）、做差异/相关/降维/生存/富集统计、整理真实数据、或要求高 DPI 可发表级出图时使用。

## 一、准备阶段（一次性）

1. **下载安装 WorkBuddy**  
   前往 WorkBuddy 官网下载并安装（安装包一路下一步即可）。安装完成后登录你的账号。
2. **安装 R 与 RStudio（强烈建议自己先装好）**  
   本 skill 内置 `ensure_pkg()` 会在首次绘图时**自动帮你安装缺失的 R 包**（CRAN + Bioconductor），  
   但 R 语言本体和 RStudio **最好你本地先装好**，能省去自动安装时的等待与权限弹窗：
   - R 本体：<https://cloud.r-project.org/>
   - RStudio（桌面版）：<https://posit.co/download/rstudio-desktop/>
   > 如果你没装，skill 在运行前也会检测并提示你去上面的链接安装，不会偷偷静默装系统软件。
3. **新建一个干净的任务空间**  
   在 WorkBuddy 里新建一个任务（对话），**单独用一个干净空间**，避免和历史文件混在一起。  
   把你要绘图用的**原始数据文件**（`.csv` / `.xlsx` / `.txt` 等）放进这个空间。

---

## 二、告诉 AI 你的数据在哪

1. **建一个 `data_path.txt`**  
   在空间里新建一个文本文件 `data_path.txt`，里面**只写一行**：你的数据文件**绝对路径**，例如：
   ```
   C:/Users/你的用户名/WorkBuddy/任务空间/abundance.csv
   ```
   这样 AI 能直接读到你的数据位置，不用你一次次手动贴路径。

---

## 三、安装本 Skill

1. **把“安装命令”发给 AI**  
   复制下面这行（命令内容你后续自己定，这里先留占位）发给 AI：
   ```
  现在为你安装Skill，先来检查是否已安装Red Skill商店，请根据 https://redskill.xiaohongshu.net/install.md 安装RedSkill 商店，然后安装r-topjournal技能。若已安装，则直接安装 r-topjournal 技能。
   ```
   AI 会据此帮你安装本 skill。
2. **等待自动安装 R 包**  
   安装完成后，skill 会**自动用 `ensure_pkg()` 帮你安装绘图所需的 R 包**（CRAN + Bioconductor）。  
   如果你在第二步已经自备好 R 环境，这一步会非常快；否则它会自动拉取，耐心等即可。

---

## 四、每次绘图的使用流程

1. **给 AI 说清三件事**（直接打字发给他）：
   - **画什么图**：例如「分组柱状图 + 显著性标注」「PCA 散点图」「相关性热图」「生存曲线」。
   - **原始数据在哪**：直接给 `data_path.txt` 里的路径，或把文件挂到对话里。
   - **生成文件存哪**：默认落在 `./results/<时间戳>/`，你也可以指定一个文件夹。  
     示例话术：
   > 用 `C:/.../abundance.csv` 画一个分组柱状图，按物种分组、按处理上色，并标注显著性；  
   > 结果存到 `./results/` 下。
2. **等待 AI 运行**  
   它会自动完成：读你的真实数据 → 清洗/整理成绘图格式 → 自动安装缺失 R 包 → 顶刊级绘图 →  
   导出（SVG / PDF / PNG / CSV 多格式）。
3. **AI 跑完返回给你这些内容**
   - ① 生成的图（可直接下载）；
   - ② 数据说明与筛选机制（你的数据被怎么处理的）；
   - ③ 关键数值占比与科学解读；
   - ④ 文件清单 + 复现命令（`R_analysis_report.md`）。

## 五、常见问题

- **Q：我不会写 R，能直接用吗？**  
  A：能。你只要给「数据 + 想画的图」，R 代码由 skill 自动生成并运行，你拿到图和分析报告即可。
- **Q：我的数据是中文路径 / 中文列名，会乱码吗？**  
  A：skill 内置 `read_table_robust()` 做了多编码容错；若仍乱码，会在报告里提示你改用英文路径。
- **Q：图能不能改成我想要的配色 / 主题？**  
  A：可以，在话术里说明即可（如「用色盲友好配色」「Nature 风格」）。
- **Q：怎么拿到最新版 skill？**
